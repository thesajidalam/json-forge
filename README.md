## Why JsonForge?

Every developer Googles "json formatter" at least once a day. Most tools are bloated, ugly, or unreliable. JsonForge was built to be the **last JSON tool you'll ever need** — fast, clean, and powerful.

- **Instant formatting** — paste JSON, see beautiful output in milliseconds
- **Full validation** — pinpoint errors with exact line and column numbers
- **Tree view** — explore deeply nested JSON with expandable/collapsible nodes
- **Multiple formats** — convert to CSV, YAML, or TypeScript interfaces
- **JSON diff** — compare two JSON objects side-by-side
- **Dark & light themes** — because developers have preferences
- **Keyboard shortcuts** — `Ctrl+Enter` to format, `Ctrl+L` to clear
- **File I/O** — upload `.json` files, download formatted output
- **Mobile responsive** — works beautifully on any screen size

## Features

| Feature | Description |
|---------|-------------|
| **Format** | Pretty-print JSON with customizable indentation |
| **Minify** | Compress JSON to the smallest possible size |
| **Validate** | Real-time validation with error location |
| **Tree View** | Interactive expandable tree with search |
| **CSV Export** | Convert JSON arrays to CSV |
| **YAML Export** | Convert JSON to YAML format |
| **TypeScript Types** | Auto-generate TypeScript interfaces from JSON |
| **JSON Diff** | Visual comparison of two JSON objects |
| **Syntax Highlighting** | Color-coded output for readability |
| **Drag & Drop** | Drop `.json` files directly into the editor |
| **Copy to Clipboard** | One-click copy of formatted output |
| **Download** | Export as `.json`, `.csv`, `.yaml`, or `.ts` |
| **Dark/Light Theme** | Toggle with full theme support |

## Quick Start

```bash
# Clone
git clone https://github.com/thesajidalam/json-forge.git
cd json-forge

# Install
npm install

# Dev
npm run dev

# Build
npm run build
```

Then open [http://localhost:5173](http://localhost:5173).
